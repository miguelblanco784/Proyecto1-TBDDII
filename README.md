# Pharmacy Management System with MongoDB

A Java Swing desktop application created as an academic database project to manage pharmacies, warehouses, products, pharmacists, owners, laboratories, and purchasing workflows using MongoDB.

The project demonstrates document-oriented data modeling, MongoDB collection operations, relationship handling, and desktop interface development.

## Main features

- Register and manage pharmacies and warehouses
- Maintain medicine and product records
- Manage pharmacists, owners, and laboratories
- Associate personnel and products with pharmacy locations
- Support warehouse purchasing and product-assignment workflows
- Create, read, update, and delete MongoDB documents
- Display collection data through Java Swing lists and dialogs
- Work with BSON documents through the MongoDB Java driver

## Main collections

- Pharmacies
- Warehouses
- Products and medicines
- Pharmacists
- Owners
- Laboratories

## Technologies

- Java
- Java Swing
- MongoDB
- MongoDB Java Driver
- BSON documents
- NetBeans

## Project structure

The application combines:

```text
Swing interface       Forms, lists, dialogs, and user workflows
MongoDB operations    Collection queries and CRUD operations
Document modeling     Business entities stored as BSON documents
Application logic     Relationships, purchases, and assignments
```

## Running the project

1. Clone the repository.
2. Install and start MongoDB.
3. Open the project in NetBeans.
4. Review the MongoDB connection settings and database name for your local environment.
5. Confirm that the MongoDB Java driver dependencies are available.
6. Build and run the application.
